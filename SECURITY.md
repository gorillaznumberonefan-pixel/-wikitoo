Security Policy

Reporting a Security Issue

If you find a security vulnerability or other security problem in Wikitoo, please report it privately rather than posting the details publicly.

Please include:

* What the problem is
* How you found it
* What part of Wikitoo is affected
* Any steps needed to reproduce it

Please do not attempt to access, modify, or delete information that does not belong to you.

Supported Versions

The latest version of Wikitoo is the supported version.

Response

Security reports will be reviewed as soon as possible. If the issue is confirmed, it will be addressed when practical.
